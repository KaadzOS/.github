# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to **kaadz@protonmail.com**. Do not open a public issue for an unpatched vulnerability.

Include the affected version or release tag, the component involved, and enough detail to reproduce the issue. Reports are read at that address; if an issue is confirmed, a fix and coordinated disclosure will follow.

## Scope

This policy covers the KaadzOS image, its build and release pipeline, the `kaadzos` pack manager, and the organization's hosted services. Debian packages themselves should be reported through Debian's security process.

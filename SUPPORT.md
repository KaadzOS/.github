# Support

## Before asking

1. Read the [manual](https://kaadzos.pages.dev/docs/).
2. Check the [release notes](https://github.com/KaadzOS/KaadzOS/releases) for your version.
3. Search existing issues.

## Where to ask

- **Usage question or bug:** open an issue in [KaadzOS/KaadzOS](https://github.com/KaadzOS/KaadzOS/issues) with the release, firmware mode (BIOS or UEFI) and steps to reproduce.
- **Package or archive problem:** include the output of `apt-cache policy kaadzos-pack-defs` and the `sources.list` stanza you use.
- **Security vulnerability:** do not open an issue. Use the [security policy](SECURITY.md).

This project is maintained in spare time. There is no support SLA. A clear, reproducible report is the fastest way to get help.
